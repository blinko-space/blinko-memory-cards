# Blinko Memory Cards

Create question-and-answer decks and study them with a tactile 3D flip. Explicit Again, Hard, and Good feedback schedules the next review without any background job.

Decks are installation-owned App entities. The App requests no network, notification, or background authority.

## Development

```bash
bun install
bun test
bun run typecheck
bun run validate
bun run build
```
